# Data Engineering Learning Log & Projects

Welcome to my Data Engineering repository! This project tracks my hands-on workflow building data pipelines, mastering SQL, and manipulating datasets using Python and Pandas.

## Project Overview
- **Goal:** Design and deploy clean, industry-standard data processing workflows.
- **Tech Stack:** Python 3, Pandas, SQL, Docker, WSL2 (Ubuntu), VS Code, Git/GitHub.
- **Status:** Active Development 

## Repository Layout
```text
├── data/
│   ├── raw/          # Immutable source datasets (read-only)
│   └── processed/    # Cleaned outputs generated by pipeline scripts
├── sql/              # SQL queries and database setup scripts
├── notebooks/        # Jupyter notebooks for data exploration
├── src/              # Modular Python extraction & transformation scripts
├── .gitignore        # Tells Git to ignore .venv/ and sensitive data
├── main.py           # Pipeline execution script
└── requirements.txt  # Project dependencies
```
